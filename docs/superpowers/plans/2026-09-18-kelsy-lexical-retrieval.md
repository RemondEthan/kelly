# Kelsy Lexical Retrieval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Kelsy’s incorrect single-score FTS path with one asynchronous, explainable lexical retrieval pipeline that preserves card aliases and ranks original terms separately from controlled synonyms.

**Architecture:** `RetrievalQueryPlanner` produces normalized original and synonym query groups. `LexicalRetriever` runs two weighted FTS5 rankings, probes field evidence in batches, and returns structured candidates without converting BM25 to a probability. `KnowledgeStore.searchAsync` becomes the shared lexical-only API for ASK, `/find`, and `knowledge_search`; the later vector plan plugs into the same types.

**Tech Stack:** Java 21, SQLite FTS5 through sqlite-jdbc 3.47.1.0, Jackson 2.21.1, JUnit 5.10.2, `CompletableFuture`, Reactor `Mono`

**Spec:** `docs/superpowers/specs/2026-09-18-kelsy-hybrid-retrieval-design.md`

## Global Constraints

- Markdown remains the only source of truth; every SQLite table is derived and rebuildable.
- Preserve `SKILL.md` card-level alias generation, including `licence/license/许可证` and `评审/review`.
- Global synonyms are local, versioned, deterministic, and never generated by an LLM or network call.
- Preserve raw negative SQLite FTS5 BM25 values; smaller means more relevant.
- Do not expose BM25 as a probability or compare it with the removed `0.20`/`0.05` thresholds.
- ASK attaches only `STRONG` hits, at most five.
- Search hot paths must not call `Files.walk`, `reconcile`, or `reconcileIfStale`.
- JavaFX entry points consume the future asynchronously; they do not call `join()` on the FX thread.
- This plan must pass without ONNX, tokenizer, or vector model files.

## Plan Completion Gate

- All existing alias behavior remains covered.
- The global synonym resource and `SKILL.md` fixed pairs agree.
- Raw negative BM25 is preserved and weighted by field.
- Original and synonym rankings remain separately diagnosable.
- Pure synonym-only matches cannot be attached by ASK.
- `KnowledgeStore.searchAsync` works without ONNX and never reconciles on the hot path.
- The 200-query lexical golden corpus is frozen for later plans.
