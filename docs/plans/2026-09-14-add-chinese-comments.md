# UI 文件中文注释实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 Kelly 聊天应用的 UI 层所有 Java 文件添加详细中文注释，让不熟悉 JavaFX 的人也能理解代码逻辑。

**Architecture:** 逐文件添加注释，不修改任何代码逻辑。注释覆盖类/接口/方法/字段，重点解释 JavaFX 属性绑定、事件处理、场景图、组件生命周期。

**Tech Stack:** JavaFX、ControlsFX、BootstrapFX、Ikonli 图标库
